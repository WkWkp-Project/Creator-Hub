# 📥 นำเข้าอินฟลูจาก Excel — ฟอแมตคอลัมน์

ระบบมี **import + แมชคอลัมน์อัตโนมัติ** อยู่แล้ว (รองรับหัวตารางไทย/อังกฤษ + เดาด้วย fuzzy match). ไฟล์นี้บอกฟอแมตให้กรอกถูกตั้งแต่แรก

## วิธีใช้ (3 ขั้น)
1. หน้า **Directory** → กดปุ่ม **Import Data** (เฉพาะแอดมิน)
2. ในหน้าต่าง Import กด **ดาวน์โหลดเทมเพลต Excel** → กรอกข้อมูล (ลบ 2 แถวตัวอย่างสีเทาก่อน)
3. ลากไฟล์ `.xlsx` / `.xls` / `.csv` กลับเข้าไป → ระบบ **แมชหัวคอลัมน์ให้อัตโนมัติ** แล้วตรวจ/แก้ได้
4. กด **Process Import** → เพิ่ม/อัปเดตเข้าฐานข้อมูล

> 📄 **เทมเพลตพร้อมกรอก:** โหลดได้จากปุ่มในหน้าต่าง Import (หรือเปิดตรงๆ ที่ `GET /api/imports/template`) — หัวตารางแมชครบ 100% + ชีต "วิธีใช้" ในตัว

## คอลัมน์ที่รองรับ
หัวตารางใช้ได้ทั้งไทย/อังกฤษ (ตัวอย่างในวงเล็บคือชื่อที่แมชชัวร์ที่สุด). มีแค่ **ชื่อ** ที่จำเป็น ที่เหลือเว้นว่างได้

| ฟิลด์ | หัวตารางที่แนะนำ | จำเป็น | รูปแบบค่า / ตัวอย่าง |
|---|---|:--:|---|
| ชื่อ | `ชื่อ` / `Name` | ✅ | ข้อความ — เช่น `Nong Aom` |
| Handle | `Handle` / `ยูสเซอร์เนม` | | `@nongaom` |
| หมวดหมู่ | `Niche` / `หมวดหมู่` | | `Beauty`, `Tech` |
| แพลตฟอร์ม | `Platform` / `แพลตฟอร์ม` | | `Instagram`, `TikTok`, `YouTube` |
| ผู้ติดตาม | `Followers` / `ผู้ติดตาม` | | ตัวเลข — `125000` หรือ `1.2M` |
| Engagement | `Engagement Rate` | | `4.8%` หรือ `4.8` |
| Growth 30d | `Growth 30d` | | `2.5%` |
| Tier | `Tier` / `ระดับ` | | `Nano` / `Micro` / `Mega` (เว้นว่าง = คิดจาก followers อัตโนมัติ) |
| ค่าตัว | `ค่าตัว` / `Base Rate` | | `95000` หรือ `฿95,000` |
| ค่าเจนโค้ด | `ค่าเจนโค้ด` / `Code Gen Fee` | | `10000` |
| ค่าเมเนจฟี | `ค่าเมเนจฟี` / `Management Fee` | | `5000` |
| ค่าเอเจนฟี % | `ค่าเอเจนฟี %` / `Agency Fee %` | | เป็น **เปอร์เซ็นต์** — `15` (= 15%) |
| สกุลเงิน | `Currency` | | `THB` (ค่าเริ่มต้น) |
| อายุ | `Age` / `อายุ` | | `26` |
| ที่อยู่ | `Location` / `ที่อยู่` | | `Bangkok` |
| Bio | `Bio` / `ประวัติ` | | ข้อความ |
| ลิงก์ IG | `Instagram Link` | | URL เต็ม |
| ลิงก์ TikTok | `TikTok Link` | | URL เต็ม |
| ลิงก์ YouTube | `YouTube Link` | | URL เต็ม |
| ลิงก์ Facebook | `Facebook Link` | | URL เต็ม |
| ลิงก์ X / เว็บ | `X / Twitter Link` · `Website` | | URL เต็ม |
| Verified | `Verified` | | `yes` / `no` (รับ `ใช่`, `true`, `1` ด้วย) |
| คะแนนความเหมาะสม | `Brand Safety` · `Audience Alignment` · `Content Quality` · `Reliability` | | 0–100 |
| หมายเหตุ | `Notes` / `หมายเหตุ` | | ข้อความ |

## กฎการแปลงค่า (ระบบทำให้อัตโนมัติ)
- **ตัวเลข:** ใส่ `1.2M`, `฿95,000`, `5,000`, `4.8%` ได้หมด — ระบบตัด `฿ , % M/K` ให้เอง (`1.2M`→1,200,000)
- **Tier:** ใส่ Nano/Micro/Mega (พิมพ์เล็ก/ใหญ่ได้); เว้นว่าง = คำนวณจากยอด followers
- **Verified:** `yes/true/1/ใช่/จริง` = ✔, อย่างอื่น = ✘
- **อัปเดตหรือเพิ่ม:** แถวที่ชื่อ/handle ตรงกับที่มีอยู่จะถูก **อัปเดต**, ไม่ตรง = เพิ่มใหม่

## เคล็ดลับให้แมชแม่น
- หัวตารางสะกดใกล้เคียงชื่อข้างบนก็พอ — ระบบเดาด้วย fuzzy match (TH+EN) ให้
- ถ้าคอลัมน์ไหนขึ้นสถานะ **review/unmapped** ตอน preview ให้เลือกฟิลด์ที่ถูกเองได้ก่อนกด Process
- 1 ไฟล์ = 1 หัวตารางต่อ 1 ฟิลด์ (อย่ามีหัวซ้ำ)
