# คู่มือการนำเข้าข้อมูล (Import Guide)

ระบบ Auto-Matching ของ Creator Hub ช่วยให้คุณอัปโหลดไฟล์ Excel/Sheet/CSV แล้วระบบจะ **เดาว่าคอลัมน์ไหนตรงกับฟิลด์ใดให้อัตโนมัติ** คุณเพียงตรวจสอบและยืนยัน ไม่ต้องจับคู่ทีละช่องเอง

> 🔒 **เฉพาะผู้ใช้สิทธิ์ admin** — การนำเข้า (และส่งออก) ใช้ได้เฉพาะบัญชี admin · บัญชี viewer จะไม่เห็นปุ่ม Import

---

## ขั้นตอนการใช้งาน

1. กดปุ่ม **Import Data** ที่แถบด้านซ้าย
2. ลากไฟล์มาวาง หรือกด Browse เลือกไฟล์ (`.csv`, `.xlsx`, `.xls` ขนาดไม่เกิน 10MB)
3. ระบบแสดงตาราง **Column Mapping Preview** — แต่ละแถวคือคอลัมน์ในไฟล์ พร้อมฟิลด์ที่ระบบเดาและสถานะ
4. ตรวจสอบ/แก้ไข dropdown ตามต้องการ
5. กด **Process Import** เพื่อบันทึกลงฐานข้อมูล

---

## สถานะการจับคู่ (Status)

| ป้าย | สี | ความหมาย | คุณต้องทำอะไร |
|------|----|----------|----------------|
| **Matched** | เขียว | ระบบมั่นใจว่าจับคู่ถูก (คะแนน ≥ 80) | ปกติไม่ต้องแก้ |
| **Review** | เหลือง/ส้ม | น่าจะใช่ แต่ควรดูอีกครั้ง (63–79) | ตรวจสอบ dropdown |
| **Unmapped** | แดง | จับคู่ไม่ได้ (< 63) | เลือกฟิลด์เอง หรือปล่อยว่างเพื่อข้าม |

---

## หัวข้อคอลัมน์ที่ระบบรู้จัก

ระบบรองรับ **ทั้งภาษาไทยและอังกฤษ** รวมถึงการสะกดหลายแบบ ตัวอย่างบางส่วน:

| ฟิลด์ระบบ | ตัวอย่างหัวคอลัมน์ที่จับได้ |
|-----------|----------------------------|
| Name | `Name`, `Full Name`, `Influencer`, `ชื่อ`, `ชื่อจริง` |
| Handle | `Handle`, `Username`, `Insta_Handle`, `บัญชี`, `ยูสเซอร์เนม` |
| Avatar URL | `Photo`, `Image`, `Profile Pic`, `รูป`, `รูปโปรไฟล์` |
| Age | `Age`, `อายุ` |
| Bio | `Bio`, `About`, `Description`, `ประวัติ`, `เกี่ยวกับ` |
| Niche | `Niche`, `Category`, `Vertical`, `หมวดหมู่`, `ประเภท`, `สายงาน` |
| Platform | `Platform`, `Channel`, `แพลตฟอร์ม`, `ช่องทาง` |
| **Tier** | `Tier`, `Level`, `Grade`, `ระดับ`, `เทียร์`, `ขนาด` (ค่า: Nano/Micro/Mega) |
| Followers | `Followers`, `Total Followers`, `Reach`, `Subscribers`, `ผู้ติดตาม` |
| Engagement Rate | `Engagement`, `ER`, `อัตรามีส่วนร่วม` |
| **Base Rate** | `Base Rate`, `Price`, `Cost Per Post`, `ค่าตัว`, `ราคาค่าตัว`, `ราคา` |
| **Code Gen Fee** | `Code Gen Fee`, `Code Fee`, `ค่าเจนโค้ด`, `ค่าเจนโค๊ด` |
| **Management Fee** | `Management Fee`, `Mgmt Fee`, `ค่าเมเนจฟี`, `ค่าจัดการ` |
| **Agency Fee %** | `Agency Fee %`, `Agency`, `Commission`, `ค่าเอเจนฟี`, `เปอร์เซ็นต์เอเจน` |
| Instagram Link | `Instagram Link`, `IG URL`, `ลิงก์ไอจี`, `ไอจี` |
| TikTok Link | `TikTok Link`, `TikTok URL`, `ติ๊กต๊อก` |
| YouTube Link | `YouTube`, `YouTube URL`, `ยูทูบ` |
| Facebook / X / Website | `Facebook Link`, `X Link`, `Website`, `เว็บไซต์` |
| Verified | `Verified`, `Is Verified`, `ยืนยันตัวตน` |
| Notes | `Notes`, `Remark`, `Comment`, `หมายเหตุ` |

> **ค่าเอเจนฟีเป็นเปอร์เซ็นต์** — ใส่เป็นตัวเลขเปอร์เซ็นต์ (เช่น `15` หรือ `15%` = 15%) ระบบจะคำนวณยอดเงินจริงให้ = (ค่าตัว + ค่าเจนโค้ด + ค่าเมเนจฟี) × เปอร์เซ็นต์
> **ลิงก์โซเชียล** — คอลัมน์ลิงก์จะถูกรวมเข้าเป็นไอคอนคลิกได้บนโปรไฟล์อัตโนมัติ

> ถ้าหัวคอลัมน์ของคุณไม่ตรงเป๊ะ ระบบยังใช้การเทียบความคล้าย (fuzzy matching) ช่วยเดาให้ และถ้ายังไม่แน่ใจ ระบบจะตั้งสถานะเป็น Review หรือ Unmapped เพื่อให้คุณตัดสินใจ

---

## การแปลงค่าอัตโนมัติ

ระบบทำความสะอาดค่าระหว่างนำเข้าให้เอง คุณจึงใส่ข้อมูลในรูปแบบที่คุ้นเคยได้:

| ค่าในไฟล์ | บันทึกเป็น |
|-----------|-----------|
| `1.2M` | `1200000` |
| `850K` | `850000` |
| `฿95,000` / `95,000` | `95000` |
| `15%` (ค่าเอเจนฟี) | `15` |
| `Yes` / `True` | `true` |
| `No` / `False` | `false` |
| `mega` / `MICRO` (tier) | `Mega` / `Micro` (ปรับเป็นรูปแบบมาตรฐาน) |

> ถ้าไม่มีคอลัมน์ Tier มาด้วย ระบบจะกำหนด tier ให้อัตโนมัติจากจำนวนผู้ติดตาม

---

## ส่งออกข้อมูล (Export)

กดปุ่ม **Export Excel** ที่แถบด้านซ้ายเพื่อดาวน์โหลดข้อมูลทั้งหมดเป็นไฟล์ Excel หัวคอลัมน์ที่ส่งออกถูกออกแบบให้ **นำกลับเข้ามา import ได้ทันที** (round-trip) โดยข้อมูลเดิมจะถูกอัปเดตทับ ไม่เกิดข้อมูลซ้ำ คอลัมน์ "ยอดเอเจน (คำนวณ)" และ "ยอดรวมสุทธิ (คำนวณ)" เป็นค่าที่คำนวณไว้สำหรับอ่านเท่านั้น ระบบจะไม่ import กลับ

---

## การนำเข้าซ้ำ (Upsert)

ถ้านำเข้าไฟล์ที่มี `handle` หรือ `name` ตรงกับข้อมูลเดิม ระบบจะ **อัปเดตทับ** แทนการสร้างซ้ำ ทำให้คุณใช้ไฟล์เดียวกันอัปเดตข้อมูลเป็นรอบ ๆ ได้อย่างปลอดภัย

---

## ไฟล์ตัวอย่าง

ในโฟลเดอร์ `sample_data/` มีไฟล์ให้ทดลอง:

- `influencers_sample.csv` — หัวคอลัมน์ผสมไทย/อังกฤษ จับคู่ได้ครบทุกคอลัมน์
- `influencers_sample.xlsx` — มีคอลัมน์ `Internal Ref` ที่ตั้งใจให้จับคู่ไม่ได้ เพื่อสาธิตสถานะ Unmapped

ลองอัปโหลดเพื่อดูการทำงานของทั้ง 3 สถานะได้ทันที
