## 2. ขอบเขตที่ทดสอบ (Coverage)

- **Auth:** login ถูก/ผิด, token หาย/ปลอม/หมดอายุ, `/auth/me`
- **สิทธิ์ (RBAC):** viewer อ่านได้ทุกหน้า แต่เขียน/ลบ/อัปโหลด/import/จัดการผู้ใช้ → `403`
- **Influencers:** CRUD, validation (avatar URL, social links, tier, ชื่อว่าง), filter ตาม tier/ราคา/หมวด, 404
- **Tiers:** กำหนดอัตโนมัติจาก followers, คำนวณใหม่เมื่อ followers เปลี่ยน, ตั้งเองทับได้
- **Campaigns:** CRUD, validation สถานะ, filter ตามสถานะ, 404
- **Imports/Uploads:** จับคู่คอลัมน์ (ไทย/อังกฤษ), แปลงค่า, ตรวจชนิดไฟล์, เฉพาะ admin
- **Stats:** overview, niche-performance, financials (โครงสร้าง response)
- **User management:** สร้าง/แก้/ลบ/รีเซ็ตรหัส, username ซ้ำ, รหัสสั้น, **กันลบ/ลดสิทธิ์ admin คนสุดท้าย และกันลบตัวเอง**
- **Export:** บล็อกถ้าไม่มี token, ผ่านเมื่อแนบ `?token=`

## 5. ข้อควรระวังของผู้ทดสอบ

- การทดสอบกับ **เซิร์ฟเวอร์จริง (live)** อาจแก้ข้อมูลในฐานข้อมูล dev เช่น เปลี่ยน role บัญชี — ควรทดสอบบนฐานข้อมูลแยก หรือกู้ค่ากลับหลังทดสอบ
