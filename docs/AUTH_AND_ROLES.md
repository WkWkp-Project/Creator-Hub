# การยืนยันตัวตนและสิทธิ์ (Auth & Roles)

Creator Hub เป็นแอปที่ต้องล็อกอินก่อนใช้งาน มี 2 บทบาท: **admin** (ผู้ดูแล) และ **viewer** (ลูกค้า/ผู้ชม)

---

## 1. บัญชีเริ่มต้น (Default logins)

ตัวติดตั้ง (`python -m app.seed`) สร้างบัญชีเริ่มต้นให้ — **ควรเปลี่ยนรหัสผ่านก่อนใช้งานจริง**

| Username | Password | Role |
|----------|----------|------|
| `admin`  | `admin123`  | admin |
| `viewer` | `viewer123` | viewer |

---

## 2. บทบาทและสิทธิ์ (Roles)

| ความสามารถ | admin | viewer |
|------------|:-----:|:------:|
| ดู Directory / Profile / Analytics / Campaigns / Financials | ✅ | ✅ |
| Export Excel/CSV | ✅ | ✅ |
| เพิ่ม / แก้ไข / ลบ อินฟลูเอนเซอร์ | ✅ | ❌ |
| สร้าง / แก้ไข / ลบ แคมเปญ | ✅ | ❌ |
| Import ข้อมูล + อัปโหลดไฟล์ | ✅ | ❌ |
| จัดการผู้ใช้ (เพิ่ม/แก้/ลบ/รีเซ็ตรหัส) | ✅ | ❌ |
| เปลี่ยนรหัสผ่านของตนเอง | ✅ | ✅ |

> **บังคับ 2 ชั้น:** ฝั่งหน้าจอซ่อนปุ่มของแอดมินสำหรับ viewer (CSS `body.is-viewer [data-admin-only]`)
> และฝั่งเซิร์ฟเวอร์ตรวจซ้ำด้วย `Depends(require_admin)` ทุก endpoint ที่เขียนข้อมูล viewer จึงเรียก API เขียนตรง ๆ ก็ได้ `403`

---

## 3. การจัดการผู้ใช้ (หน้า Settings · เฉพาะ admin)

- **เพิ่มผู้ใช้** — ตั้ง username, ชื่อ, สิทธิ์ และรหัสผ่าน (มีช่องยืนยันรหัสผ่านกันพิมพ์พลาด + ปุ่ม 👁 ดูรหัส)
- **แก้ไขผู้ใช้** — เปลี่ยนชื่อ/สิทธิ์ และตั้งรหัสผ่านใหม่ได้ (เว้นว่างถ้าไม่เปลี่ยน) · username แก้ไม่ได้
- **ลบผู้ใช้** — ลบได้ ยกเว้นบัญชีตัวเอง
- **ตัวกันพลาด:** ระบบไม่ยอมให้ลบหรือลดสิทธิ์ **admin คนสุดท้าย** (กันล็อกตัวเองออกจากระบบ)

ผู้ใช้ทุกคนเปลี่ยนรหัสผ่านของตนเองได้ที่ Settings → บัญชีของฉัน (ต้องกรอกรหัสปัจจุบัน + ยืนยันรหัสใหม่)

---

## 4. กลไกภายใน (สำหรับนักพัฒนา)

| ส่วน | ไฟล์ | รายละเอียด |
|------|------|-----------|
| แฮชรหัสผ่าน | `security.py` | PBKDF2-HMAC-SHA256, 200k rounds, salt 16 byte → เก็บเป็น `pbkdf2_sha256$rounds$salt$hash` |
| Token | `security.py` | payload JSON (`sub`, `role`, `exp`) เซ็น HMAC-SHA256 ด้วย `SECRET_KEY` รูปแบบ `base64(payload).base64(sig)` |
| Dependency | `deps.py` | `get_current_user` อ่าน token จาก header `Authorization: Bearer` หรือ query `?token=` · `require_admin` ตรวจ role |
| Endpoints | `routers/auth.py` | login, me, CRUD ผู้ใช้, เปลี่ยน/รีเซ็ตรหัสผ่าน |

อายุ token ตั้งที่ `token_ttl_hours` ใน `config.py` (ค่าเริ่มต้น 7 วัน)

---

## 5. ความปลอดภัย — ก่อนขึ้น production

1. **ตั้ง `SECRET_KEY`** ใหม่ผ่าน environment variable (อย่าใช้ค่า default ในโค้ด) — เป็นกุญแจเซ็น token
2. **เปลี่ยนรหัสผ่าน** บัญชี `admin`/`viewer` เริ่มต้น หรือลบทิ้งแล้วสร้างใหม่
3. ใช้งานผ่าน **HTTPS** เสมอ (token เดินทางใน header)
4. token เก็บใน `localStorage` ของเบราว์เซอร์ — เหมาะกับเครื่องมือภายใน หากต้องการความปลอดภัยสูงขึ้นพิจารณา httpOnly cookie + CSRF
